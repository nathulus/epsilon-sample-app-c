# Installer Autre après un reset

Un **reset efface toutes les apps externes**. Il faut réinstaller à chaque fois.

## Fichier à envoyer

- `C:\Users\Fouquet\Desktop\Autre.nwa`  
- ou `Téléchargements\Autre.nwa`  
- Taille attendue : **~73 Ko**, nom affiché par l’outil : **Autre**

## Étapes (Chrome)

1. Calculatrice **allumée**, câble USB, **pas** en mode examen.
2. https://my.numworks.com/apps → compte connecté → **Connect** si demandé.
3. Quand la zone « Select a NWA file » s’affiche :
   - **Glisser-déposer** `Autre.nwa` depuis le Bureau dans la zone blanche, **ou**
   - Cliquer **Select a NWA file** → Téléchargements → `Autre.nwa` → **Ouvrir**.
4. **Autre** doit apparaître dans la liste. Cliquer **Install** (ou équivalent jaune).
5. Attendre la fin **sans débrancher**. Message de succès dans le navigateur.

Sans l’étape **Install**, l’app **n’apparaît pas** sur la calculatrice.

## Sur la calculatrice

Touche **maison** → faire défiler les icônes à droite → **Autre**.

## Si l’app n’apparaît toujours pas

- Refaire **Connect** sur le site.
- Autre onglet Chrome uniquement.
- Réessayer **Install** avec le nouveau `Autre.nwa` du Bureau.
